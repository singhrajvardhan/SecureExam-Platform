# 📘 SmartExam Documentation

**AI-Powered Online Examination & Proctoring System**

---

## 1. 📌 Introduction

**SmartExam** is a secure, AI-driven online examination platform designed to ensure **fair assessments and prevent cheating**. The system integrates **real-time monitoring, automated evaluation, and role-based access control** for students, teachers, and administrators.

---

## 2. 🎯 Objectives

* Ensure **exam integrity** using AI proctoring
* Provide **automated and accurate evaluation**
* Enable **real-time monitoring of students**
* Offer **detailed analytics and performance insights**
* Build a **scalable and secure exam platform**

---

## 3. 🏗️ System Overview

SmartExam consists of three main user roles:

### 👨‍🎓 Student

* Register and login securely
* Attend exams
* View results and analytics

### 👨‍🏫 Teacher

* Manage students and questions
* Monitor exams
* Analyze performance

### 👨‍💼 Admin

* Full system control
* Manage users and exams
* Monitor platform activity

---

## 4. 🧾 Student Workflow

### Registration

Students provide:

* Full Name
* Father’s Name
* Mother’s Name
* Email
* Phone Number
* Address
* Date of Birth

After registration:

* Application ID (4-digit) generated
* Roll Number (5-digit) generated
* Details sent via email

---

### Login

Students log in using:

* Application ID
* Roll Number
* Date of Birth

---

### Dashboard

* Personal details
* Exam history
* Previous scores
* Security logs (tab switching, etc.)

---

### Exam Process

* Start exam from dashboard
* Questions are randomly generated
* Each question carries **4 marks**
* Negative marking: **-1 per wrong answer**
* Copy/paste disabled
* Tab switching monitored

---

### Result

* Instant score display
* Accuracy and performance shown
* Stored in dashboard
* Shared with teacher/admin

---
